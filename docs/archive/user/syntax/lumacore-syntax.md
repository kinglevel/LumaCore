# LumaCore

Canonical language source: `docs/user/syntax/lum.md`

This document captures the current intended high-level identity of LumaCore.

## Identity

`LumaCore` is an open lighting control system built around a terminal-first
console workflow.

At the simplest level, it is:

- a shared show-control runtime
- a tree-shaped show model
- a console-style command language
- a live output system for lighting and future show engines

## Core Language

LumaCore combines four ideas:

- `LumaCore`
  - the whole system
- `Luma`
  - the runtime cursor and operating presence inside the system
- `Lum`
  - the command language
- `TreeShell`
  - the tree-aware shell world for navigation and inspection
