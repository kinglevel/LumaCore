# Values

Canonical language source: `docs/user/syntax/lum.md`

This document captures the current intended high-level definition of `Value`
in `Lum`.

## Principle

In `Lum`, a `Value` is the content being applied, stored, or compared.

Examples:

```text
At 50
Full
Zero
Set User ParseSummary On
Set Fixture 1 Label "Front Left"
```

## Main Value Families

- numeric values
- text values
- boolean values
- symbolic values
