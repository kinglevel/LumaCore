# User Manual

What operators, show designers and users need to know.

Chapters follow the order operators learn in — syntax comes early because the
command language is used everywhere. Hand-written pages explain concepts and
guide; the syntax of every word lives in the generated reference (chapter 0).
Every page describes what the station does today; an open item is one line pointing at
the roadmap, and the designs for features that aren't built live under `visions/`.

## 0. Reference (generated)
- [commands.md](reference/commands.md) — every command word: syntax, aliases, rights, scope, examples
- [objects.md](reference/objects.md) — every object keyword: verbs, tree place, writable properties

Generated by `cargo run -p lumacore-station --bin gen-docs` from the registries — never
edit by hand; a test fails when it is stale.
