### The phone round in one paragraph

`kit/phone.js` is the phone rule (short side < 500 px → `up` / `side`); `kit/sheet.js` is the one
sheet every phone pop-up wears. On a phone `<luma-setup>` folds its chrome (state chip, tree chip
→ sheet, the grid's selection bar in its No cell) and its slab into one bar (`<luma-slab bar>`:
what works now · Oops · ⋯ More · the lock); on its side the bar is a column on the right. Slab
actions have `short` labels. Insert fixtures is Type → Mode → Place on a phone; the Universes map
is a list of cards; the slot grid is rows of 10 upright; the context menu and the value dialog
are the sheet. New UI on a phone uses `phoneMode()` / `openSheet`, never its own width query.

## Tests

The e2e suite is **green and ~4 min** (2026-10-19, after this handoff was first written). Spec
files run in parallel, one worker each (`playwright.config.ts`: half the cores, at most 8,
`E2E_WORKERS=n`), every server on a free port block (`support/server.ts`); tracing is off unless
`E2E_TRACE=1`. Serial it was 23 min with 24 failures that hid 148 tests behind them (a serial file
stops at its first failure). Fixed that day, by cause: stale tests behind decided changes (the
quoted property of `Set`, E-CMD-007's text, the zip show file, the `.versions/` folder, `Toggle
Menu` on the ⚙ key, the Showroom's stand-in, the phone's folded setup frame), the harness
(`CLIENT_PROTOCOL` 17 → 20 — the monitor and CLI helpers were refused; Node 20 has no
`WebSocket`, the feeds tests run theirs in the page; `zipEntries`, `box`), and product bugs
(`Set ▸` completion after §33 3c3; an enum setting's labels as Lum words; the Oops chips' bare
property; the pool's scroll across a pitch change; the shell dropped a `Suggest` behind queued
keys; the surface lost the password field's focus on a status; the No cell's menu closed on its
own click; a `close_menu` behind a loading `open_menu`; `EditSetting` is a read for every rights
shape; touch sizes — the grid's ⋯ chip, open / order buttons, narrow column headers (their ⋮ goes,
hold opens the menu), the tree search, the setup rail, the picker's tabs; later the same day: the Edit chip beside its cell, a
header's "twice" by state, the split handle on the profile's double time, the surface redrawing
only on a change). Under eight workers one or two tests a run can still fail from load alone
and pass alone — the known mechanism: Playwright sends a tap as touchstart, a round trip,
touchend, and at load 40 that gap can pass the 500 ms hold, so the kit sees a hold (the context
menu or the edit card opens over the next target); a real finger is never that slow. Run the
file again before digging, or `E2E_RETRIES=1`.

Per step run only that step's tests (cargo build + filtered tests; `phone.spec`, `kit-34g4`,
tidy, catalog); the full suite when a kit file or the harness changed.
