What C wrote
  • Addresses, IDs and positions were switched on, so they are in the draft, with a tick and the live value under them.
  • Names and type revisions were switched off, so they are offered: an outlined cell with the file's value under it, unticked.
  • New fixtures are in the draft and in Luma layer House.
  • LOST fixtures are only marked; Delete is a tick.
Small marks
  • The GUID column is blue when the GUID was the match (the usual patcher mark).
  • A gold-light dot: Bob's own edit in the draft (104's name).
  • A violet dot: a live edit by someone else that reached the draft (Alice's invert pan).
  • A red cell: the clash, never taken; Keep waits until it's resolved.
Leaving the patch
  • Keep asks: "8 new, 19 changed, 4 LOST kept, 4 offers not taken, 1 clash." The clash blocks Keep.
  • Keep is one Oops step. Discard drops the import and Bob's edits; Alice's live fix stays on the live show.
