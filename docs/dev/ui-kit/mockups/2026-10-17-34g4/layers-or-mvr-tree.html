  • 2 moved to Truss 3: the import asks, Keep / Move.
  • New group Truss 4: the import asks, suggesting a new layer.
  • 3 questions, plus the Automatic setting and the source mapping to maintain.
  • 4 new on Truss 2: they land in "Mid truss", the same group found by UUID. No question.

  • Truss 4: arrives as a new group (NEW row in the tree).

Export MVR
  • A switch: By MVR layer (CAD's tree back) | By Luma layer (Bob's sorting).
  • Luma-only layers get a UUID once, kept in Metadata.
  • The tree as it is, with no switch. Vectorworks sees "Mid truss" and the "Specials" group.
  • Lossless: import → export → import changes nothing.
  • The tree as it is (CAD's own structure). Tags aren't exported.
  • Lossless for CAD, and Bob's sorting stays private.
