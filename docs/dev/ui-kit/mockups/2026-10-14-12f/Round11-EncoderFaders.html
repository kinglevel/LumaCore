Concept A, as you picked: four fixed encoder sections, the familiar layout but smarter, laid out like your Dynamic Presets v2.0.

Layers side by side. Each attribute has three vertical faders next to each other: Value · Fade · Delay (in an effect: Hi · Lo · BPM · Phase). The chosen layer's fader widens and the others stay narrow but keep their numbers, so timing is always in sight. The Layer button cycles; tapping a narrow fader picks its layer for every encoder. Values / Effect n of m switches the set.
Feature strip (taller, easier to hit), with a smart mini indicator per feature group. Some are live and follow running effects:

  • Dimmer: four level bars showing what each fixture outputs.
  • Position: four dots on a tiny stage.
  • Gobo: each fixture's current gobo.
  • Colour: each fixture's colour.
  • Beam: a cone as wide as the zoom and as bright as the iris.
  • Focus: a dot that blurs.
  • Control: the lamp state.
  • Shapers: the beam with its blades.
Marks: the red corner = programmer values, a moving ∿ = an effect runs, ◢ = programmer timing.
Phone: no pages. Swipe sideways through every attribute of the feature, and drag up and down on a fader to change it.
Pop-ups (channel sets, colour picker, slider panel) close with a tap anywhere outside. This becomes a rule for every pop-up in the UI. Whether the interface dims behind a pop-up is a user profile setting.
