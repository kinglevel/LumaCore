One preset pool that follows the programmer

There are no preset pool types to pick. All presets live in one numbered pool, and each Presets window shows the presets that touch the feature group selected on the encoder bar. Tags narrow it further. Store keeps everything that is active in the programmer, and the window files the new preset under every feature group it touches.

What a cell shows

  • Top bar: how the preset fits your selection. Green fits every selected fixture, yellow fits some, and the whole cell dims when it fits none. Teal (the pool colour) means nothing is selected.
  • Number, use count, mode letter: the cyan number counts the fixtures using the preset now, from your programmer and the running cues. S is Selective (per fixture) and U is Universal (one value for every fixture that has the attribute). Global, per fixture type, comes later.
  • Live preview is drawn from the stored values, so there are no images to make: a colour swatch, a pan/tilt dot, a dimmer level, a shutter or FX glyph. A mixed preset shows one preview per feature group.
  • Feature-group squares along the bottom, one per encoder-bar group, lit in the group's colour when the preset holds values for it.
  • Pink frame: the preset is in your programmer.

What the lines are

  • A tap runs the window's tap action: At Preset 4, SelFix Preset 4; At Preset 4, SelFix Preset 4, Call Preset 4.
  • Store Preset takes the next free number. Store + a tap on an empty cell gives Store Preset 23. The tags lit on the chip row are assigned at the same time: Store Preset 23; Assign Tag "Song 3" At Preset 23.
  • The window's own state is one Set line each: Set Self "FeatureGroup" Follow, Set Self "Tags" "Song 3", Set Self "Layout" Packed.
  • Edit opens the preset editor: its values per fixture and attribute, in a <luma-grid>.

Questions for this round

1. The filter rule

Try all three with the Filter menu: pick Color, then select Blinder.

Recommended
Touches the group
Every preset with values in the group. Mixed looks show under each group they touch; presets that don't fit the selection stay visible, dimmed.
Only the group
Pure presets only. Mixed looks show only on All. Tidy, but your show looks get harder to find.
Touches + fits selection
Hides what can't apply to the selection, so the pool shrinks as you select. Fastest to scan, but presets seem to vanish.

2. Packed or fixed slots

Recommended
Packed, with fixed as a window setting
Packed by default: visible presets close up in number order, with a few empty cells at the end for storing. A window can switch to fixed slots for muscle memory.
Fixed only
Each preset keeps its place in every filter; hidden ones leave dim gaps.

3. The encoder bar's "All" tab

Recommended
The window shows every preset
All on the encoder bar drops the feature-group filter; tags still apply.
Mixed looks only
All shows only the presets that span two or more groups (the old All pool).

4. Numbering on the command line

Recommended
Preset 12
One number in the one pool. This changes lum.md (Preset is two-part today), so it gets its own decision record first. A two-part Preset 4.1 from another console is read only when a show is imported.
Keep Preset 4.1
The first part becomes meaningless with one pool.
