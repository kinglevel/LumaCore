RunTool and EditTool

One tool for the whole user, in every window, dialog and screen. RunTool (default): a tap runs the object (a group selects its fixtures, a cue goes), a hold takes the window to full screen. EditTool: a tap picks, a drag on an object moves it, a drag on empty space lassos, right-click or hold opens the context menu. Press the EditTool key on the sidebar (or ` here — the real hotkey is a UI key you bind). Picks are per screen: both Group pools on Screen 1 share them; Screen 2 has its own. Tab focuses the next window (click the screen first).

What each window does
  • Group pools — Run: Group 3. Edit: tap picks (both pools show it), drag a group onto a slot = Move Group 3 At 9, drag on empty space lassos.
  • Sequence sheet — Run: Goto Cue 3. Edit: picks cues, lasso, the menu.
  • Universes — Edit: picks rows. Run: open — select as today, or run its action?
Window focus with Tab
  • Tab focuses the next window, Meow+Tab (Shift) the one before; the focused window has a frame.
  • In it, arrows move a cursor, Enter taps (runs in RunTool, picks in EditTool), the Menu key opens the menu in EditTool.
  • On the command line Tab completes what you typed; on an empty line it goes to the windows.
Esc: back to normal
  • Every Esc puts you on the command line and undoes one layer, the top one first:
  • 1 a menu or dialog closes · 2 a full-screen window comes back · 3 the picks clear · 4 EditTool goes off (RunTool).
  • Press it a few times and you are always in the normal state with the command line selected.
