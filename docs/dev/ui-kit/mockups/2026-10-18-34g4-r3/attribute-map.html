2 · Wheels and gobos, slot by slot — the smart picker

Stepped values can't be scaled: each source slot points at a target slot. Tap a target to open the picker for the targeted fixture: best matches first (colour by ΔE2000 from the slots' CIE colours, gobos by family and name), then every slot of its wheel with swatches / gobo pictures, a search, and for colour Mix it with CMY instead (exact colour, wheel open). The suggestion is pre-filled; a hand pick turns solid gold.

3 · Native values — and a range that changes later

Every stored value is native: degrees, Hz, kelvin, a CIE colour, a slot by its GUID — never a DMX byte. The DMX is computed from the fixture's current GDTF range every time the plan is compiled. So Meaning holds twice: on a type change, and when a later revision changes a range — the stored 90° stays 90° and only the DMX moves. DMX output (the switch) converts once, at the change: it stores the native value the old byte meant on the new fixture, and from then on that is native too.

4 · Update fixture types — including one that breaks things

One list of the show's fixture types whose file in library/gdtf/ is newer, with what changed. Tap a row for its items. A must resolve item (a mode in use is gone) blocks Update until you pick a fix; a warning (addresses that now overlap, a removed wheel slot cues use, a smaller range, renamed attributes) has a pre-filled fix you can change; info needs nothing. Nothing changes until Update; each type is one Oops step. The Spiider row is an example of a breaking revision — pick a fix for its first item.

Rules this mockup shows

One window
A type change and Clone open the same Map & clone window: From → To, What (object kinds, ticked), the map. A type change converts what's ticked and keeps the unticked values as they are (unused on the new type, listed); Clone copies what's ticked. Between the same type the map part folds away.
What
Three columns of object kinds: Values (cues by sequence, presets by pool, programmers by user, parked values), Places (groups with order and grid spot, tags; later layouts and pixelmapper mappings), the fixture itself (offsets, inverts, MasterReact; name, note) — never the patch. Quick sets: All values, Everything, Only cues, Only presets.
Connect to
A press on any source opens its menu: suggestions first (same feature / geometry), every target attribute by group with what already feeds it, a search, Keep unused; several targets can be ticked. The Color row offers how colour converts: through colour, only the wheel, only CMY, or split. A drag from the dot still works.
Defined attributes
A sub-dialog of this window: the show's rules in order with the built-in GDTF families below; Try a name to see which rule answers.
Native values
Stored values are native (degrees, Hz, K, CIE, slot GUIDs); DMX is computed from the current GDTF range at every plan compile, so a later range change recalculates DMX and never touches the value. A held value keeps what it wanted and is retried.
Picker
Wheel and gobo targets open a picker for the targeted fixture: best matches by ΔE2000 / family + name, every slot with pictures, search, Mix with CMY.
Updates
Must-resolve items block Update until a fix is picked; warnings carry a pre-filled fix; each type is one Oops step; the map opens for renamed / removed attributes with values.
