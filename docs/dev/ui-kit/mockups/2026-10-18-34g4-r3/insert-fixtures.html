Insert fixtures · round 3 · v6

Mockup for the 34g4 round 3 hardening (decisions §34, 2026-10-18). Patch › Draft › Insert fixtures… opens two steps built from kit elements: 1 Choose a type, revision and mode, reading its channel map and the file's details; 2 Place them on the DMX sheet. Every field writes part of one Store Fixture line, shown live; nothing happens until Create. Data: this station's real library/gdtf/ and the demo show (six MAC Aura XB at 1.001).

1 · Choose — type, revision, mode

Two views of the same choice (it opens on the No list, Details off; the left part changes, Mode and the channel map stay put): the No list — the show's fixture types by number (No, Name, Manufacturer, Revision, its modes as chips with their footprint, Used); tap a mode chip to pick type and mode at once — and Manufacturer · Type · Mode, the columns, which also reach the library's files (Show / Library / Both). Both views keep the channel map and the details. The search covers manufacturer, type, short name, revision text and mode names (the one suggestion engine). Each type shows where it comes from: in this show, a file in library/gdtf/. The channel map sorts by Structure (the GDTF geometry tree), Channels (DMX order) or Feature group (Dimmer, Position, Color, Beam, Focus, Control — GDTF's groups). Details shows the file's metadata.

2 · Place — how many, where, under what

The form on the left, the DMX sheet on the right: the universe's 512 slots with the fixtures already patched there, and the new block in gold where it would land. Tap a free slot to put the block's first fixture there, drag one fixture to give it its own address (only that one moves; it adds a Patch line after the Store), or Shift (Meow) + drag to move the whole block; it snaps to slots and turns red where it would overlap; ← → changes universe. A block that runs onto other fixtures or past 512 shows red here and in the grid afterwards — Create still runs it and both fixtures of an overlap are parked until resolved (decided: resolve it in the patch, no question). Under First FID and Address, the free chips — the same as the renumber / address value dialog's — offer blocks that fit the quantity.

Fixture types tab — GDTF's own fields

The columns follow GDTF's FixtureType (its attribute names under each header), plus the show's own Note and Tags. A reference console's tab has the same core — Source, ShortName, LongName, Description, Manufacturer, Used, CanHaveChildren, Version, OriginalFileName — plus console-only ones (Scribble, Appearance, Color, SpecialPurpose, MVRObjectType) that LumaCore covers elsewhere or leaves out. Import opens step 1 on Library with Import instead of Next; Upload from this device puts a file into library/gdtf/ first.

Rules this mockup shows

One line
Create runs exactly the line at the bottom: Store Fixture … /Type … /Mode … [/Revision n] [/Address u.aaa] [/Offset n], with Import FixtureType "…" first for a library type. One Oops step each.
Channel map
Read from the chosen mode: offsets per break, attribute (its pretty name and GDTF name), the geometry it sits on and its feature (from the GDTF attribute table). Structure groups by geometry (Base › Yoke › Head › Beams, Auras), Feature group by Dimmer / Position / Color / Beam / Focus / Control / Shapers / Video; a virtual channel (no DMX) shows "Virtual".
Details
From the file: Description, ShortName / LongName, FixtureTypeID, GDTF version, the newest revision's text, date and uploader id, file name and size, a thumbnail when the file has one.
Two views
No list (the show's types by number; the default, Details off) and Manufacturer · Type · Mode (with the library); both with the channel map and the details; "Library…" in the list jumps to the columns on Library.
Drag
A new fixture drags on its own (same drag engine as the DMX map): only it moves and the line gains ; Patch Fixture n At u.aaa. Shift (Meow) + drag, the Address field or a free chip moves the whole block.
DMX sheet
The same DMX map element the Universes tab's Map view and Edit Patch use (zoomed in): rows of 16 or 20 slots, a fixture's first slot labelled with its FID, the new block in gold, overlaps red. Tapping a free slot sets Address.
Red, not asked
A block that would overlap or pass 512 is red here and in the grid; Create still runs it, and an overlap parks both fixtures until resolved.
Free chips
First FID and Address show free blocks that fit the quantity (with the footprint and offset), from the one free-value index the value dialog and the command line use.
