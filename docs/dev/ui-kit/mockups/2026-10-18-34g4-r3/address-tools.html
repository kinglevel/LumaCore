Address tools · round 3

Mockup for the 34g4 round 3 hardening (decisions §34, 2026-10-18, item 18): swapping addresses between two selections, and the kit-wide renumber — lasso, type the first number. Both start from the grid's own selection (tap, Shift adds, drag on rows lassos) and end in one line. Data: the demo show's six MAC Aura XB (14 ch) on universe 1, three Robin BMFL WashBeam (48 ch) on universe 2.

1 · Swap addresses

Select A (gold), press Swap addresses…, then select B (blue) the same way — tap or lasso. The grid previews every pair, old → new, in selection order. A fixture with a different footprint keeps the start address of the one it swaps with; whatever then overlaps turns red and parks both, as everywhere (nothing asks). Swap writes one line. Try: lasso 101–103, Swap addresses…, lasso 104–106, Swap.

2 · Renumber — every list and grid

Lasso or select, then just type a number (or press Renumber…): the selection is numbered from it. Selection order numbers in the order you picked (tap order, or the lasso's direction); Grid order in the grid's current sort. A number that is taken by an object outside the selection is red; Skip taken jumps over it, Swap gives that object the selection's old number (the door's rule for a taken slot). One line through the object door. The same gesture works in a pool — try the Group pool below.

Rules this mockup shows

One lasso
Every list and grid lassos the same way (the kit's one drag engine): drag on rows or tiles, Shift adds, the device's Drag: Auto | Lasso | Scroll decides touch.
Typing renumbers
Digits typed with a selection in a grid or pool open the Number from strip with them in it; Enter runs it, Esc cancels. The command line keeps its keys everywhere else.
Swap
Pairs in selection order; a different footprint keeps the partner's start address; overlaps park both and list as conflicts.
Lines
Swap and renumber each write one line, one Oops step; the exact words go through lum.md first.
