Round 3 (2026-10-18, decisions §34 round 3, items 9–11 and 18). The patch window as one piece: the claim button bottom-right — hold it (the gold fill runs left → right; let go early and it drains back) to claim the Devices draft, press the gold Claimed button to leave (Save / Discard / Cancel when the draft changed). Live edits only the live columns — every other cell and its header carries the lock. Draft edits every column, each cell its one line. Try: hold the button; then tap a Mode cell and give 102 "Mode 2"; right-click a row; tap greyed slab cells to read why.

Approved (§34 round 3, 18): Copy / Cut stay greyed in the Live patch — a copied fixture is a new fixture, so it needs the claim.

The claim button
  • The slab's last cell, bottom-right, on a phone too. Live (open lock, green edge): a hold of 0.6 s runs Claim Root.ShowData.Devices; the gold fill runs left → right over the hold and drains back if you let go early (reduced motion: no fill, it just switches). A press only shows the hint "Hold to claim and edit".
  • Claimed (gold, closed lock): a press runs Unclaim Root.ShowData.Devices — Save / Discard / Cancel when the draft changed, straight back to Live when not. The ✕ asks the same.
  • Claimed · Bob (dashed, grey): a hold does nothing; the hint names Bob. Kit-wide, the hold ring is drawn above dialogs.
Live vs Draft columns
  • Live columns: Name, Address, X / Y / Z, Master react, Note — they change at once, your own Oops step, and the holder's draft follows (a cell the holder changed is refused, naming them).
  • Every other cell, and its header, shows the lock: "Claim the draft to change it" (Bob's: "Bob holds the draft").
  • Draft: every cell is its one line — FID = Move Fixture, Type / Revision / Mode = the picker (then the attribute map when it asks), MVR group = pick list, Tags. Gold dot = your draft edits; violet = someone's live edit that reached your draft.
  • A footprint that now overlaps, or a deleted universe, shows in the Address cell: red with ⚠ until resolved, or "no universe".
Slab states
  • Greyed cells stay in place (dashed, grey icon); a tap tells why in a toast.
  • Live / Bob's: New, Copy, Cut, Delete, Import… need the claim; Select, Oops, Export…, Edit (live columns) work.
  • Paste is greyed with an empty clipboard and counts what it holds ("Paste 2"); Copy / Cut / Delete / Edit count the selection.
  • New = Insert fixtures… (the same dialog as the function block's and the grid's new line).
Function block
  • Insert fixtures… · Patch to… · Next free address · Multipatch… · Info · Sort · Clone… · Offset.
  • Patch to… and Next free change an address, a live column, so they work in Live; Insert fixtures… and Multipatch… need the claim.
  • The context menu on the rows (right-click / hold / ⋯) carries the same, plus Set for every column (context-menu.html) and Renumber… (renumber.html).
