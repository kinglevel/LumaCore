5 · Rules this mockup shows

One Edit Patch
Every way in opens the same dialog on the selection (or the fixture you came from); the universe shown is the first fixture's. It is a floating dialog over the patch window, like the value dialog grown up — Esc and ✕ close it, and its Identify / Probe end with it (Off Identify Fixture Thru; Off Identify DMX Thru).
Quick vs full
Patch to… stays the quick way (one address, Apply). Edit Patch is for looking: where things are, Find, Identify, Probe, several breaks, moving runs on the grid.
Lines
Opening Edit Patch runs nothing. Tapping a slot runs Assign Fixture n At DMX u.aaa; Find and Identify run their Identify lines; each tool is one line as decided.
Live
An address is a live column: Edit Patch works in Live and in your draft; Insert fixtures needs the draft.

To decide: which ways in exist. Recommended: the function block's Edit Patch… cell, Slot grid… in the value dialog, Edit Patch… in the context menu, and zoom in on a universe in the Map view. The Address cell keeps opening the value dialog.
