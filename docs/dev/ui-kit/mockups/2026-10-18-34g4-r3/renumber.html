One value dialog
Small, floating beside the selection (never over it), draggable by its header; a bottom sheet on a phone. Big field, − / + steppers, one hint line, up to four free-value chips, the value's own toggles, Apply. Enter applies, Esc cancels, ↑ / ↓ step.
Preview behind
Every keystroke re-draws the list behind it (old → new, rows in the way red); nothing is sent until Apply — one line, one Oops step.
Free values
The chips come from one free-value index per object kind (the suggestion engine's, which also suggests them after At on the command line); they fit the selection's size.
Any value later
The dialog takes a value kind (number, address, …) with its parser, step, free index and toggles from the registry — Renumber and Address are the first two.
