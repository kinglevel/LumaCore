DMX map · round 3 · v2

Mockup for the 34g4 round 3 hardening (decisions §34, 2026-10-18): one kit element, the DMX map, at two zooms — the Universes tab's Map view and Edit Patch — with the address tools taken from other consoles (Titan, Eos, ONYX, Capture). Every button writes one line. Data: the demo show's six MAC Aura XB on universe 1 (1.001–1.084); universe 2 holds two Robin BMFL WashBeam and a third that overlaps the second, to show a conflict.

1 · Universes › Map — zoomed out

A bar per universe: each fixture a block (FID, name, range), coloured by type; dashed runs are free — tap one with fixtures selected to patch them there. Drag a block along its bar or onto another universe's bar: the ghost snaps to slots, gold when free, red when it would overlap; dropping writes one Patch line (a selected block takes the whole selection with it, keeping its layout). The usage bar and count under each universe name show channels in use of 512 (Titan). An overlap is striped red, and both fixtures are parked: they keep their addresses and programming but send nothing until resolved. The conflict list below the map has one-tap fixes. Try dragging 303 onto 302, or 106 onto universe 3.

2 · Edit Patch — zoomed in

An Address cell or Patch to… opens it for the selected fixtures: the fixtures on the left with a cell per break, the universe's slot grid on the right (an Edit Patch). Tap a slot = the current fixture (or its next break) lands there; drag any fixture's run in the grid (gold = the selection, blue = others) and drop it on another slot — the selection moves together; with Keep spacing the rest follow in selection order keeping their gaps, with Bunch up they close up after it (Titan, Capture). The function row gathers the established consoles' tools.

3 · Identify, probe, find

Identify flashes the selected fixtures (their intensity at full, dropping to 15 % every other second — Eos's Flash) outside every programmer, until you stop it or leave. Probe (ONYX's Highlight Tool) does the same to a raw address: tap any slot, even an unpatched one, to find what is there. Find (Titan) moves the current fixture's address one footprint at a time while it flashes — when the real unit reacts, Patch here. All three are the station's own output, never stored, never replicated, and stop when the dialog closes. Try Probe above, then tap slot 1.150.

Decided: Identify / Probe / Find need Setup and up, at any time; while one flashes, the dialog shows a red warning strip with Stop, because it goes out on the live rig (§34 round 3, 18).

Rules this mockup shows

One element
The DMX map draws a universe as a bar (Map view) or as a slot grid (Edit Patch, Insert fixtures' sheet); the data is the same feed.
Usage
Channels in use of 512 per universe (a multipatched or overlapping slot counts once).
Drag
A fixture's block (Map) or run (Edit Patch) drags to any slot or universe; the ghost snaps to slots and shows red where it would overlap; a drop is one Patch line, a dropped overlap is allowed and parks both.
Conflicts
An overlap or a run past 512 is red, listed, and both fixtures are parked (send nothing) until resolved; nothing asks at patch time.
Never stored
Identify, Probe and Find are station output only — no programmer, no Oops step, no replication; Setup and up; a warning strip while one runs.
Lines
Patch to / Next free / Swap / Unpatch / Renumber each write one line; their exact words go through lum.md first.
