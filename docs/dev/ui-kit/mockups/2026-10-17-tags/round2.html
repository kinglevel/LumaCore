Tags, round 2

There is no Tags section under Show. Tags are given in the one EditSetting overlay of any show object, which has the object's own tabs plus Meta and Tags (a picker tree). The Tags pool window is the overview: two panes, the tree with + / − and the picked tag's members. The patch sidebar can group by tag, with a Direct | Deep switch. The ≡ menu and the Tags cell work everywhere. Pick a state below. The command lines are sketches for the lum.md discussion.

EditSetting, one for every object
  • Tabs: the object's declared sections first (a fixture: Patch, Position, Behaviour), then Meta (Name, Note, Colour, Icon, Locked, Hidden, plus read-only GUID, path, used by) and Tags.
  • The Tags tab is a picker tree with + / −, a search box, and tri-state boxes over several objects. Each tag has its ≡ menu, and "New tag here" makes one in place. Every change is one Assign / Unassign line.
  • The same overlay for a sequence, a group, a preset, an MVR group: only the object's own tabs differ.
Pool window = overview
  • Left: the tree with + / −, colour, counts and the Action badge. Right: the picked tag's members by kind, Direct or Deep.
  • A tap on a tag selects it here. "Run action" runs its Action, or the window's default (Select fixtures today; Go+ / Off planned).
  • Hold for the ≡ menu, drag to re-parent. The window bar holds the default Action and Direct | Deep.
Patch sidebar by tag
  • Group by: MVR tree · MVR class · Tags. Members: Direct | Deep.
  • Deep: Lx1 shows its own fixtures plus Right's and Left's, marked "from Right". A fixture with two tags shows under both.
  • "Untagged" lists fixtures with no tag. Dropping fixtures on a tag runs Assign.
