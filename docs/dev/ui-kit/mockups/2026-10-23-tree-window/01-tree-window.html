The Tree window

A window type for the web and the app that shows the same tree and inspector as the shell's NAV mode. Use it when you need to point at a path, a GUID or a part of the tree, for example while discussing a bug, a design or a show.

It is built only from existing pieces. The tree is <luma-tree>, fed by the same row builder as ls and NAV. The inspector is the same lumacore-views inspector the shell draws, with its values as settings cells. Copying goes through kit/clipboard.js. So the web, the app and the shell can never show different things.

Questions

  1. Editing.
    A Values are settings cells: tap one to change it, and every change is one Set line, as in EditSettingrecommended
    B Read-only; a value only puts its Set line on the command line
  2. Follow (a window setting, the chip in the window bar).
    A None / Selection (picking fixtures or tapping a pool object moves the tree there) / My NAV (it mirrors your terminal's NAV cursor); Selection by defaultrecommended
    B None and Selection only
  3. The path bar. Click it to type or paste a path or a GUID and jump there; the crumbs move up. recommended Should a pasted GUID also find objects that were deleted (from Oops)?
  4. Copy. A copy icon on each identity row (GUID, Path, target), plus the row menu: Copy GUID / Copy path / Copy as target / Copy Set line. recommended
  5. Shared with NAV. Bookmarks (per user) and the ● changed markers are the same in both. Should the row menu also have "Open in the terminal's NAV"? recommended
  6. Phone. The tree fills the pane, and a tap opens the inspector as the one phone sheet. recommended

How it is built

  • A window type tree declared in the Rust registry, with settings Follow, Show (all / changed only) and Split (the tree / inspector ratio).
  • Two feeds on /ws/feeds: tree (the rows of the open branches, from tree_rows) and inspector (one path, from lumacore_views::inspector). Both are rebuilt when the show changes, never on a timer.
  • Every gesture is a command line: a value change is Set, the reset icon is Reset, a bookmark is the same line as NAV's. Jumping, folding and Follow are the window's own view state, kept like any window setting.
  • The row menu is the one context menu from the registry, plus the copy entries.
  • Kit only: <luma-tree>, settings cells, <luma-menu>, the toast and kit/clipboard.js. The window waits for nothing new except the path bar, which would join the kit and the Showroom.
