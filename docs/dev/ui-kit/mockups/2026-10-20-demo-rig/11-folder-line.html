What a folder does on a line

Decided: a folder is a fixture with children (3, 4), an internal key and an order (5, 6), ids FID · type · CID (7), named Fixture Media 7003 or Fixture Generic n (8, 10). Now the behaviour: what Fixture Media 1 on a line means, what the grid and the sidebar show, what Move and Delete carry.

Facts

The deskMedia 7003 resolves to the folder object itself (count 1, 286 children); Media 1 Thru 9 to the five folders that exist in that range. The established rule for the Grouping fixture type: selecting it selects everything below it, and programming it programs the children (stated from the manual, not probed — the API reads objects, not the programmer).

The Patch dialog todayTree sidebar: MVR tree (layers › groups) · Class · Tag; picking a node filters the grid; the grid is flat, FID order; the kind rail; the claim button.

A folder on a line

A · Recommended

The subtree, like the desk; the folder itself with /Only

Fixture Media 1 selects every fixture below Stage 1 Mainstage, in tree order; Fixture Media 1 At 50 programs them; Fixture Media 1 Thru 9 is the union. The folder itself is in the selection too (it has no attributes, so values pass it by) — that is what Move, Delete, Set … "Name" act on. /Only on a line (or a tap on the folder row in the grid) takes the folder alone. Delete asks Keep / Delete the children as MVR nodes do; Move carries the subtree and asks on a nesting change (the one nesting rule).

  • + the desk's behaviour; one rule for folders, groups and layers in the sidebar
  • + a folder with no children is just a fixture of a channel-less type

The folder only; the subtree with /Children

Fixture Media 1 is the folder; Fixture Media 1 /Children its subtree.

The grid and the sidebar (no question: follows A)

  • The sidebar's MVR tree shows layers › groups › fixtures-with-children, any depth, counts per node; picking a node shows its subtree in the grid.
  • The grid keeps its flat views (FID order, by universe) and gains a tree view in parent + order: folders as rows with a disclosure and the count, children indented one level per depth; the No cell of a folder shows its id (Media 7003) in grey where a FID would be. The two-line review cell and this share the grid's row-height work.
  • Insert fixtures… and Import place new fixtures at the end of the picked node (the next free order); drag in the tree re-parents through the lift gesture and the nesting ask.
  • Export writes the tree back: ChildList per folder, in order.
