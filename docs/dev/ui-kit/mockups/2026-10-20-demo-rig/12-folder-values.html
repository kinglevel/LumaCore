Where a value given to a folder lives

Your direction on 11: Fixture Media 1 selects only the folder; At 50 on it sends the value down to the fixtures; a value can also go to the folder itself; any fixture may contain fixtures; sub-fixtures of a fixture are never a thing here (the part / element system comes later) — a fixture is a fixture. This page pins the one word in that which decides the engine: "sends down".

"Sends the value down"

A · Recommended

The folder holds the value; the fixtures below inherit it

Fixture Media 1 At 50 stores Dimmer 50 on the folder. At compile time every fixture below that has no value of its own for Dimmer, in that programmer or cue, takes the nearest ancestor's. Store Preset / Store Cue keep the folder's value as one entry; a cue with "Stage 1 Mainstage Dimmer 50" is one line, not 1 255. Selecting one fixture and giving it 30 overrides it for that one. Clear on the folder clears the folder's value. Tagging a fixture elsewhere changes nothing; moving a fixture into a folder changes what it inherits.

  • + the tree is the programming structure — your words; stages, trusses and types become one-value handles with no group pool needed
  • + small data (one entry), exact Oops, replication unchanged
  • − the plan compiler learns one walk (nearest ancestor per attribute); LTP between a folder value and a child's own value needs a rule (the child's own wins while it exists; a newer folder value does not take it)
B

Fan-out: the folder keeps nothing

Fixture Media 1 At 50 writes 50 into each of the 1 255 fixtures' values, one Oops step; the folder stays empty. "Directly to the folder" then means the folder's own attributes only (a parent fixture that has channels).

  • + the desk's behaviour; no engine change
  • − a stage-level cue is 1 255 entries; nothing in the data says "the stage was set", only that every fixture was
C

Both, by a word

A is the plain line; /Down (or Fixture Media 1 Thru — the folder's members) fans the value out into the fixtures when the operator wants per-fixture copies to tweak.

  • + A's data with the desk's gesture when wanted
  • − two things one line can mean; the word is a lum.md addition
