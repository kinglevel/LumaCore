A · Recommended

The sources; the show is built, not committed

library/mvr/ti2026.mvr and library/poolxml/ti2026-groups.xml are committed. gen-demo builds library/shows/demo.luma from them through the station's own lines (Import Mvr "ti2026.mvr", Import PoolXml "ti2026-groups.xml" Groups, the users and lines, SaveShow "demo"); the file is gitignored. The e2e support, the screenshots script and the station's start build it when it is missing or older than the sources or the binary (0.5 s in release). The demo test builds it and checks its counts and a golden of the normalized JSON without the GDTF bytes (as normalized does today) — so a show change still shows up in review, as a diff of the golden, not of a zip.

  • + no 8.6 MB per format bump; the sources are the truth
  • + a fresh checkout works: the first start builds the show
  • − one more "build when missing" rule (the station, the e2e support, the scripts share one door for it)
