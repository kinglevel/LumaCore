A · Recommended

Fixture Media 7003 — as lum.md has it

The kind sits inside the fixture's id; the object word stays Fixture. Everything a fixture path allows follows: Fixture Media 7003 DMX, Fixture Media 1 At 50, Fixture Media 1 Thru 9, and with the default object Fixture> a bare Media 7003 is written out as Fixture Media 7003 (the bare-id rule, §33 21) — so the desk's habit still types.

  • + already decided and built; no clash with Effect or any future word
  • + one object, one completion (Fixture Media <Tab>: the Media ids)
  • − two words where the bare form types one, unless Fixture is the default object
B

The bare Media 7003

Each id type becomes an alias of Fixture that fixes the kind: Media 7003, Channel 12. A new alias kind in the registry ("an object word with a kind preset").

  • + the desk's lines paste in unchanged
  • − Effect 3 is an effect already; the fixture kind Effect needs another word or goes
  • − nine more object words in one namespace (Media, Channel, Marker, Fog, Pyro, Houselights, NonDim, Universal, …), each one a word no other area may take
