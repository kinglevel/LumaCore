Where the groups come from

A · Recommended

A small pool XML reader: formats/lumacore-poolxml, Groups first

Import PoolXml "default-groups.xml" Groups [/Drive] [/DataPool]: reads a DataPool XML export, makes one LumaCore group per exported group in the selected DataPool, members by fixture id (FID; a second-id item by its type), grid cell from X / Y, order kept; a group whose items are all sub-fixtures is reported and skipped. The demo builder runs it after the MVR import. Presets, sequences, macros are later parts of the same reader, each when its LumaCore object exists.

  • + the groups the show really used, 87 of them, with their grid
  • + the reader is the first step toward reading a whole exported show, which this DataPool folder is
  • − a new format crate and a new word (lum.md: Import PoolXml) — a day
