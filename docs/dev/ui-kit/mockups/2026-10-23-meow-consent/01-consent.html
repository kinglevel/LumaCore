The Meow consent on every login

Before the repo goes public, every login asks the user to accept the Meow License: on the station page, in the app, in the terminal and after an autologin. The station holds the question as one server dialog (the rule one-server-held-dialog), so every client shows the same ask and none confirms on its own. Until the user consents, the login is not finished: no screen, no feeds that need a user, no lines.

How it is built

A successful /api/login (or Login line) does not hand out a working session straight away. The station marks the login as pending consent and returns one held dialog to that client only. Its buttons are lines: Consent finishes the login, Logout drops it.

A pending login gets only the open feeds and the station view, the same as before a login. Every other line is refused with a new error code until the user consents.

No show-format change. The wire gains one dialog kind, so SESSION_PROTOCOL and CLIENT_PROTOCOL go up by one. The decision goes in a new record.
