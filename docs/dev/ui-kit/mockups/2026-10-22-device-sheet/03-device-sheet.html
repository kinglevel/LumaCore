The miniature and the phone

Already decided (12e round 5): the miniature is the hybrid. Fix and Name as text, Dim a level bar with the value on top in programmer colour when it is yours, Color a swatch, selected fixtures with a blue edge. Drawn here from the same rows. On a phone the pane stays a miniature; holding it opens the window full screen in Channel mode, the one that fits a short side.

To decide on this page

1. The name. The roadmap says device sheet; established consoles say Fixture Sheet, and LumaCore's object is Fixture.
A · recommended
“Device Sheet”: the Devices claim and menu already use the word, and the sheet will also show things that aren't lights (fog, machinery, the camera).
B
“Fixture Sheet”: what a console operator looks for.
2. Modes in the first build.
A · recommended
Fixture and Channel; Dimmer+ when feature-group selection exists on the encoder bar.
B
All three at once.
C
Fixture only.
3. Folders as tree rows: what does a folder row show? A value at a folder fans out to every fixture below (the programmer's Direct / Down switch defaults to Down).
A · recommended
The common value when every fixture below agrees, a faint “·” when they differ. Bars when anything below is in your programmer. As drawn.
B
The name only; value cells empty.
C
No folder rows; a flat list in patch order, folders only in the patch dialog.
4. What the sheet shows when it opens.
A · recommended
Every fixture, Selection first on. Programmer only and Selected only are toggles on the bar, each a Set Self "…" line kept on the window.
B
Follow the selection: only selected fixtures, everything when nothing is selected.
5. Columns across types.
A · recommended
The union of the attributes in scope, under feature-group headers, a black cell where a type has none. The grid's column sets: Condensed = each group's main attributes, Full = all, Extended = all plus readouts like CTO in K.
B
One block per fixture type, each with its own header row.
6. A tap on a value cell.
A · recommended
Tap selects the fixture and puts the attribute on the encoder bar (two lines, as shown). A second tap on the same cell opens the calculator, and Enter runs Fixture 785 Attribute "Pan" At -45. Hold: the one context menu.
B
Tap opens the calculator at once.
7. Layers in the first build. Absolute, Fade, Delay, Output, DMX as drawn. Relative and the phaser layers appear when those values exist. Your current sheet keeps Auto off and Absolute on; is Auto (follow the encoder bar's layer) wanted from the start?
