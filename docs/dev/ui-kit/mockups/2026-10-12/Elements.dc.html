Element gallery

Each element is a luma-* custom element drawn from a server descriptor. Every gesture runs a command line. Try the swipe button, toggle, fader and the hold button.

luma-button

Guest sees actions disabled, not hidden. Hold shows a ring; at 500 ms it means "show me more".

luma-swipe · luma-toggle

Choice → swipe button (few options) or segmented row. Bool → toggle with lamp. Each tap is one Set line and one Oops step.
