What the grammar gives — and what it doesn't

lum     = [ select-op ] [ verb [ phase ] ] [ if-early ] [ target ] { slot } [ if ] { option } ;
option  = "/" NAME [ value ] ;       (* whether it takes a value: declared on the option *)
value   = NUMBER | relative | spread | WORD | QUOTED | LINE | SELF-READ | target ;
target  = item { set-op item } ;      (* MvrGroup 3, Tag "Truss", MvrLayer 1 + 2 *)
WORD    = a word of the vocabulary — a choice is typed bare (Auto, Take), quoted is text

One value per option. A value may be a target, so /Scope MvrGroup 3 is grammar today. A list of words after one option (/Offer Addresses + Names) is not: + is a set-op between ids, and a bare word list has no rule.
