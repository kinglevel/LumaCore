Real capture — the grid the review takes over

The draft today
PatchDraft { owner, live, marks } on the state: the holder's whole Devices, the live copy, the violet marks per cell. The patch feed (per user) carries mode draft | live, the holder, the rows with the Fixture's columns, the MVR tree, runs and conflicts. A holder gone 5 s loses the draft; Unclaim asks Keep / Discard.
The grid
Rows by key, selection + / − / Thru / All / None / Invert / lasso, one line naming its rows ({rows} = the numbers), the context menu per cell, the slab's cells from the registry. A row tick is a selection; a cell's own choice is a context-menu line.
Statuses
Same · Changed · New · Lost · Outside (matched beyond the scope, "Bring into …") · Clash (an address or number another row holds; never taken, blocks Apply until unticked or resolved).
