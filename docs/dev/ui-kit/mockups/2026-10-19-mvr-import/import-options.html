The file
An .mvr is a zip: the scene XML (layers › child lists › fixtures with UUID, GDTFSpec + GDTFMode, Addresses, FixtureID, UnitNumber, classing, matrix; AUXData) plus the GDTFs it names — often 20–300 MB. Embedded GDTFs go to the fixture type store by SHA-256 like any upload. crates/formats/lumacore-mvr reads it (not built yet).
