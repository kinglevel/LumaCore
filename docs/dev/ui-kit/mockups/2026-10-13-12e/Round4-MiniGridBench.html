Miniature <luma-grid>

This is a round-4 bench for 12e. The same list is drawn four ways in a miniature pane of the same size. Each fills its pane edge to edge and keeps the live row in view (the running cue, or the selected fixtures). Drag the pane size, switch the list, and press Go to see the running cue move.

List
The four candidates: A shrinks the full-screen grid to fit. B is the grid at a mini density, with its columns stretched across the pane. C draws the data as bars instead of a table. D keeps the key columns as text and turns the others into small graphics: bars for times and levels, an icon for Trig, a swatch for colour.
