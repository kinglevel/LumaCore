# End-to-end tests (Playwright)

Every spec file runs on the demo show — the rig (decisions §40 14: 1 348 fixtures and 23
folders, universes 1–255 with gaps, 77 groups; built from its sources by the global setup). A
test names the rig's facts or steps past them (groups 85+, universes 109–186, numbers 20000+);
a virtual grid draws only the rows in view, so a test takes a row it can see.

Drive the real interface in Chromium: the server's web UI with its lock / login surface, the same UI
in app mode, and the app's connect page. Each spec file starts its own `lumacore-server` in a temp directory (fresh library,
station id and users) on a free block of ports, with `--RootMonitor`, so sysmon can be asserted. Your
running server and show are never touched. Spec files run in parallel, one worker each (half the
cores, at most 8; `E2E_WORKERS=n` sets it); the tests inside a file share its server, in order.

```bash
cd tests/e2e
npm install          # once (Playwright 1.59.1; uses its cached Chromium)
npx playwright test  # builds lumacore-server (http feature) first (support/global-setup.ts)
npx playwright test tests/login-sysmon.spec.ts -g "Debug"   # one file / test
E2E_ECHO='login|detached' npx playwright test               # print matching server lines
E2E_TRACE=1 npx playwright test                             # keep a Playwright trace of every failure
E2E_RETRIES=1 npx playwright test                           # rerun a failed file once (a pass then counts as flaky)
```
